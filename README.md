# 雙階層曼陀羅九宮格思考法 (Mandala Thinking Method)

一個支援 81 格雙階層展開的曼陀羅九宮格思考與創作工作坊網頁工具。

## 🌟 特色功能
- **雙階層 81 格架構**：從中心核心目標向外擴散 8 大子主題，再深入展開 64 個實踐細節。
- **三種思考路徑**：支援螺旋順序型、十字面向型（SWOT）、水平放射型。
- **多元匯出格式**：支援高畫質 PNG 圖片、A4 橫向 PDF、條列大綱 Markdown 及專案 JSON 備份。
- **純前端零依賴**：單一 HTML 檔案，離線可開，無需後端與資料庫。
